This is a handy trick to execute custom script or executable on target machine if you lack execute permission

Lack of execute permission can put some guys to halt, but not all.

This trick will help you to execute a script or executable even if you are lacking execute permission.

**/lib/x86_64-linux-gnu/ld-2.23.so &lt;EXECUTABLE&gt;**
